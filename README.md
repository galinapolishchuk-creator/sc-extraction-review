# Extraction Review — прототип (SC Records)

Интерактивный прототип страницы ревью извлечённых данных соглашения.
React + Vite, сборка выходит **одним самодостаточным HTML-файлом**.

Кейс: Reyes Songs LLC, co-publishing. Данные вымышленные.
Экран выверен по эталонному фрейму Figma `199:11794` (файл Agreements).

## Что живое

- sticky-бар ревью: scroll-spy активной секции, клик по флагованному чипу ведёт
  к первому нерезолвленному флагу, счётчики тают
- флаги: Confirm / Link existing резолвят, правка значения резолвит мгновенно,
  Undo возвращает
- Terms: пересчёт End Date / Collection End / Rights End от Effective Date
- Rates: наследование от Standard Rate, NON-STANDARD + reset, переключение
  активного сета, история ставок, ряд Wraparound по переключателю
- Advances: условия, список райтеров с indeterminate, живой пересчёт сводки

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | дев-сервер с живой перезагрузкой |
| `npm run build` | однофайловая сборка → `dist/index.html` |
| `npm run smoke` | сборка + прогон страницы в jsdom (35 проверок рендера и кликов) |
| `npm run check-tokens` | ищет CSS-переменные, которые используются, но не объявлены |

Сборка открывается двойным кликом с диска: скрипт собирается классическим IIFE,
потому что модульный браузер по `file://` блокирует.

## Структура

```
src/
  styles/      слой токенов + стили, порядок импорта = порядок блоков исходника
  ui/          зеркало компонентов SC Library (Field, Checkbox_RS, Button…)
  screens/
    ExtractionReview/
      data.js            кейс: секции, реестр флагов, авансы, ставки
      ReviewContext      состояние флагов (resolve/undo) и счётчики
      ContractContext    Effective Date, сроки, Wraparound — общие для секций
      sections/          14 секций
```

## Правила, на которых это держится

- **Стили переносятся с сохранением каскада.** В исходнике есть намеренные
  дубли (`.mxhead`, `.copt`, `.md`, `.advset`) — поздний блок побеждает.
  Порядок `@import` в `styles/index.css` менять нельзя.
- **Экраны собираются только из компонентов `ui/`**, а не из сырых div-ов.
- **Цвета — только через семантические токены.** `styles/tokens.css` = три
  блока: имена 1:1 с Figma Semantic, короткие алиасы-ссылки на них и отдельный
  блок значений, которым семантического аналога пока нет.
- **Значения снимаются пикселем с канваса.** Фолбэки в `get_design_context`
  отдают значение переменной в дефолтном моде и расходятся с тем, что
  отрисовано во фрейме.
- **Сверка — скриншот-к-скриншоту** с фреймом в Figma, кропами в одном масштабе.

## Известное расхождение с канвасом

Счётчик флагов считается по фактическому содержимому: «1 of 11 resolved ·
8 REVIEW · 2 NOT FOUND». На канвасе подписано «0 of 12 · 9 · 3» — канвас
рассинхронизирован сам с собой (Cure Period там уже в состоянии Confirmed).
